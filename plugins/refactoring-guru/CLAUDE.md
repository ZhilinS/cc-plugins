# Refactoring Guru Plugin

## Maintenance Rules

When adding, removing, or renaming files in `skills/refactor/references/`:

1. Update `skills/refactor/references/navigation-map.md`:
   - Update the Structure tree
   - Update the Elements or Architecture table
   - Update the Quick Reference table if needed

2. No hook changes needed — the hook uses `navigation-map.md` to discover supported languages automatically.
